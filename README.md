### 🌱 Sobre mim

- 🚀 Construo a **AMAGRO TECH** — plataforma SaaS de gestão para produtores de café: fazenda, colheita, custo por saca, clima, cotação, NDVI por satélite e o **Cafú**, um agrônomo virtual com IA que atende pelo WhatsApp.
- 🛠️ Atuo em toda a stack: arquitetura, backend, frontend, banco de dados, segurança, infraestrutura e integrações.
- 📍 Espírito Santo, Brasil.
- 🌐 [amagrotech.com.br](https://amagrotech.com.br)
